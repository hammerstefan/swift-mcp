# Triage Labels

| Canonical role | Local `Status:` value | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer evaluation |
| `needs-info` | `needs-info` | Waiting for the reporter |
| `ready-for-agent` | `ready-for-agent` | Specified for agent implementation |
| `ready-for-human` | `ready-for-human` | Needs human implementation |
| `wontfix` | `wontfix` | Will not be actioned |

Use the local value when a skill asks for a triage label.
